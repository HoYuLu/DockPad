# DockPad

> 给 Windows 补一个 macOS 风格的 Dock，再配一个能装下几百个应用的可搜索启动面板。

DockPad 是一个 Windows 桌面美化 + 启动器工具：底部常驻一条 Dock 栏放常用应用，按快捷键弹出一个可搜索、可分组、可拖拽管理的「全部应用」面板。纯离线运行，不联网、不收集任何数据。

- 平台：Windows 10 / 11（x64）
- 技术栈：Electron 33 + 原生 HTML / CSS / JavaScript（无前端框架）
- 许可：MIT

## 功能

### Dock 栏

| 功能 | 说明 |
|---|---|
| 常驻 Dock | 放常用应用的图标，单击启动；右键可从 Dock 移除 |
| 横竖自适应 | 贴屏幕底边时横排，贴左右边时自动竖排 |
| 拖动与吸附 | 左侧握把可拖动整条 Dock，靠近屏幕边缘时按设定距离自动吸附 |
| 自动隐藏 | 开启后鼠标离开 Dock 收进屏幕外，移到底边再滑出（延迟可调） |
| 始终置顶 | 可关闭：不置顶时 Dock 会待在其他窗口下面 |
| 任务栏让位 | 系统任务栏设为自动隐藏时，鼠标碰到屏幕底边，Dock 自动上移，避免与任务栏互相遮挡 |
| 悬停预览 | 鼠标悬停图标弹出窗口缩略图（可在设置里关闭） |
| 快捷按钮 | Dock 右侧四个圆按钮：显示桌面图标、此电脑、任务管理器、全部应用 |

### 应用面板

| 功能 | 说明 |
|---|---|
| 即时搜索 | 顶部搜索框实时过滤，支持中文名与原名 |
| 分类标签 | 新建 / 重命名 / 删除分类；分类可「上锁」或「设置密码」，防止误改 |
| 排序方式 | 手动排序 / 按最近使用 / 按名称 |
| 拖拽排序 | 直接拖动图标调整顺序，拖动后自动切回手动排序 |
| 拖入导入 | 从资源管理器拖文件、快捷方式、整个文件夹到面板即可导入；拖文件夹会按文件夹名建同名分类 |
| 拖拽删除 | 拖动图标时底部出现垃圾桶，丢进去即从列表移除（不动磁盘文件） |
| 批量管理 | 右键 →「批量管理」进入多选模式，可勾选后批量删除 |
| 批量添加确认 | 扫描 / 导入 / 拖文件夹时先弹出勾选清单，只添加你选中的应用 |
| 图标右键菜单 | 重命名、更换图标、更改路径、固定到 Dock、恢复默认图标、批量管理、删除 |

### 外观

| 项 | 范围 |
|---|---|
| Dock 透明度 | 0 – 100% |
| 应用面板透明度 | 0 – 100% |
| Dock 图标大小 | 36 – 64 px |
| 面板图标大小 | 36 – 96 px |
| Dock 底色 | 任意颜色（与透明度叠加） |
| Dock 按钮颜色 | 任意颜色（图标固定白色） |
| 面板底色 | 任意颜色 |
| 快捷方式名字颜色 | 任意颜色 |

调色面板在面板右上角的「◐」里，改动**即时生效**。

面板里的搜索框、分类标签、右上角三个按钮、图标名称全部跟随「面板底色 + 名字颜色」；两者亮度过近时会自动换成对比色，避免白底白字看不见。

### 设置与系统

- **全局快捷键可自定义**：打开面板 / 打开设置 / 扫描添加应用，三个动作独立设置，支持"设为不绑定"（不占用任何组合键）；被其他软件占用时自动退回内置默认组合
- **开机自启**
- **省内存模式**：关闭 GPU 加速，省掉整个 GPU 进程（重启生效）
- **应用库管理**：查看库文件位置与条目数，扫描文件夹批量添加、从文件夹导入 `.lnk` / `.url`
- **图标缓存**：首次提取后写入本地缓存，二次打开不再重复解析

## 优点

1. **Dock 的行为做得比较细**
   贴边吸附、竖排切换、自动隐藏、任务栏让位、位置记忆——这些都是原生 Dock 该有的细节，Windows 上同类工具里不多见。
2. **面板能承受几百个应用**
   600+ 图标的面板依然可以流畅搜索、滚动、拖拽；图标异步加载 + 磁盘缓存，打开不卡。
3. **配色真的能调**
   四个颜色 + 两个透明度 + 两个图标尺寸，而且控件（搜索框、分类、按钮、文字）会跟着面板配色自动算对比度，不需要手动一个个配。
4. **完全离线、无遥测**
   不发任何网络请求，不写注册表垃圾（除开机自启一项），所有数据都是可读的 JSON。
5. **数据模型简单**
   应用清单就是一个 `library.json`，备份、迁移、手改都方便，不需要数据库。
6. **对内存做过针对性优化**
   面板关闭 90 秒后自动销毁窗口回收内存，设置窗关闭即销毁，空闲时全量 GC。实测关面板驻留约 390 MB，开面板约 480 MB。
7. **免安装**
   打包版解压即可运行，不需要管理员权限。

## 缺点与局限

1. **Electron 的原罪：体积大、内存高**
   程序本体约 190 MB，常规驻留 300–400 MB。同等功能的原生程序（C#/WPF 或 Go）通常只要 100–150 MB，这是架构决定的，优化不掉。
2. **只支持 Windows**
   大量依赖 Win32 API（窗口置顶、任务栏检测、图标提取、桌面图标开关），移植到其他平台需要重写这部分。
3. **「显示桌面图标」依赖本机 Python**
   该按钮调 `tools/deskicons.py` 调用 Win32 API 切换桌面图标显隐。系统里没有 Python 时这个按钮会提示失败，其他功能不受影响。
4. **个别应用的图标取不到**
   Windows 缩略图接口对部分 exe 返回空白或"文件类型图标"。可以用右键「更换图标」手动指定，或预先生成 `icon-fallback.json` 兜底表。
5. **路径一旦变动就会失效**
   应用是按绝对路径记录的，软件移动目录或重装后会显示灰色（missing），需要在右键菜单里「更改路径」。
6. **无自动更新、无代码签名**
   升级要手动替换整包；未签名会让 SmartScreen 提示"未知发布者"，部分杀软可能误报。
7. **多显示器适配不完整**
   面板与 Dock 的位置锚定以主显示器为主，多屏 + 不同 DPI 缩放的场景没有充分测试。
8. **没有自动化测试**
   纯手工验证，回归靠人眼。

## 注意事项

- **首次启动面板是空的**
  把应用、快捷方式或文件夹拖进面板，或用托盘菜单「扫描文件夹添加应用…」批量导入。
- **数据都在 `%APPDATA%\DockPad`**
  `library.json`（应用清单）、`settings.json`（设置）、`icon-cache.json`（图标缓存）、`dock-items.json` 等。删掉整个目录 = 恢复出厂状态，建议定期备份 `library.json`。
- **升级时整包替换，不要单独覆盖 `resources\app`**
  如果替换的是旧版源码，新功能会被直接回滚，且可能出现新导出配旧函数体的崩溃。
- **快捷键冲突会自动降级**
  自定义组合被其他软件占用时，会退回内置默认组合；实际生效的是哪个，看设置页按钮上显示的文字。
- **面板全透明 + 名字颜色与底色相同**
  系统会自动用对比色兜底，但建议把「名字颜色」设为与「面板底色」有明显反差的颜色，观感更好。
- **往 Dock 拖文件导入时，只有左侧握把能拖窗口**
  图标区刻意不做窗口拖拽区，否则资源管理器的拖放事件会被窗口拖拽吞掉，导入功能就失效了。
- **未签名程序可能被杀软拦截**
  首次运行如被拦截，添加信任即可。

## 运行

### 直接用打包版

解压后双击 `DockPad.exe`。首次运行会在 `%APPDATA%\DockPad` 生成配置目录。

### 从源码运行

```bash
npm install
npm start
```

需要 Node.js 18+。

### 打包成便携版

```bash
npm run pack
```

产物在 `dist/DockPad-win32-x64/`，整个目录可直接分发。

## 目录结构

```
DockPad/
├─ main.js              # 主进程：窗口 / 托盘 / 快捷键 / 图标提取 / 任务栏让位
├─ apps.js              # 应用扫描、图标提取与缓存、库的增删改
├─ library.js           # 应用库（library.json）读写、分组、导入
├─ settings.js          # 设置读写与取值校验
├─ preload.js           # 预加载脚本，暴露 IPC 白名单
├─ renderer/
│  ├─ dock.html         # Dock 栏
│  ├─ grid.html         # 应用面板（搜索 / 分类 / 网格 / 调色面板）
│  ├─ settings.html     # 设置窗口
│  └─ preview.html      # 悬停窗口预览
├─ tools/
│  └─ deskicons.py      # 切换桌面图标显隐（Win32 API）
├─ icon.ico             # 应用图标
└─ icon-fallback.json   # 可选：预提取的图标兜底表（默认不进仓库）
```

## 技术说明

- **主进程**负责窗口生命周期、托盘、全局快捷键、任务栏让位轮询、图标提取；渲染进程只是三个静态页面，通过 `preload.js` 暴露的窄接口与主进程通信（`contextIsolation: true`，`nodeIntegration: false`）。
- **窗口策略**：Dock 常驻、面板按需创建并在闲置 90 秒后销毁、设置窗关闭即销毁——用重建换内存。
- **图标**：`nativeImage` 提取 → 缩放到 256px 内 → 写缓存；取不到时回退到 `icon-fallback.json`。
- **数据**：全部是普通 JSON 文件，无数据库、无网络。
